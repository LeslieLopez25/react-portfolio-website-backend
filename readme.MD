# Portfolio Backend

This is the backend to the my React portfolio website. This uses Resend to receive email and since Resend uses a secret API key, it can be detected by anyone in the frontend and any could send spam emails. This way, only the server knows the API key. Also the backend allows me to control how the contact form behaves and not the browser. This way there is valid input, rate limit, and to protect myself from bots.
